# Heartbeat

A family blood pressure log: record readings, see trends, and get general guidance on measuring, exercise and first aid.

- Runs entirely in the browser. Data is stored only on the user's device (browser storage). Nothing is sent to any server.
- Install on iPhone: open the site in Safari, tap Share, then **Add to Home Screen**.

Not a medical device and not medical advice. See the in-app terms of use and privacy notice.
